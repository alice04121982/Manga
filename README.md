# Manga

A marketplace and price comparison app for manga. Browse any title, see what the edition looks like (single volume, 2-in-1, 3-in-1 omnibus, box set), compare prices across sellers and shops, and list your own copies for sale with help pricing them.

Platforms: native iOS and Android app, plus a website.

Status: planning. No application code yet. Read the docs in order:

1. [docs/PLAN.md](docs/PLAN.md) - what we are building, for whom, and in what order
2. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) - the technical stack and data model
3. [docs/SECURITY.md](docs/SECURITY.md) - the security and privacy blueprint
